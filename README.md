# MyShop - MERN E-commerce Project

A full-stack e-commerce web application built with **MongoDB, Express, React, and Node.js**.  
Users can browse products, add items to their cart or wishlist, checkout, and view order history. Admins can manage products, orders, and users from a professional dashboard. The application features a responsive and user-friendly interface using **Tailwind CSS**.

## Features
- User authentication: register, login, and logout
- Browse products with search functionality
- Add products to cart and wishlist
- Checkout with order summary and order history
- Admin dashboard: manage users, products, and orders
- Responsive UI optimized for desktop and mobile
- Professional and clean design with smooth interactions

---

## Tech Stack
- **Frontend:** React, React Router, Redux Toolkit, React Query, Tailwind CSS
- **Backend:** Node.js, Express.js, MongoDB (Mongoose)
- **Authentication:** JWT

## Installation

### 1. Clone the repository
git clone https://github.com/selahadinnasir/Ecommerce.git
cd Ecommerce

### 2. Backend
cd backend
npm install
.env  # add your MongoDB URI, JWT secret, and other environment variables
npm run dev

### 3. Frontend
cd ../frontend
npm install
npm run dev
Open the app in your browser: http://localhost:5173

## Usage

1. Register or login as a user

2. Browse products and use the search bar

3. Add products to your cart or wishlist

4. Proceed to checkout and view order history

5. Admin users can manage products, orders, and users via the dashboard
